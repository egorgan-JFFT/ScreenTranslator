# Screen Translator v0.6.1 — исправление закрытия перевода

Исправлен зависающий перевод поверх экрана.

- Свайп вверх **по кнопке TR** закрывает слой перевода.
- Одиночное нажатие TR при открытом переводе закрывает его вместо повторного перевода.
- Перед показом нового результата старый слой удаляется.
- Двойное нажатие TR без открытого перевода по-прежнему переключает режим области.
- Перевод поверх текста остаётся неинтерактивным, чтобы не блокировать нажатия в магазине или браузере.

## Обновление
Распакуйте ZIP, скопируйте файлы в локальный репозиторий ScreenTranslator с заменой, затем в GitHub Desktop Commit → Push origin. APK скачайте из GitHub Actions.

Изменён код CaptureService.kt, номер версии в app/build.gradle.kts и README.md. Сборка и тестирование на устройстве не проводились.
