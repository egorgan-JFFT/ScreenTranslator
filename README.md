# Screen Translator v0.11

Изменения:
- Перевод стоит на месте оригинала и больше не сползает вниз. Блок вписывается в рамку оригинальной строки. При нехватке места рамка расширяется вправо и немного вниз (только в свободное место до соседнего текста), а шрифт уменьшается до 7 sp.
- Соседние блоки разделены разными бледными цветами (белый, жёлтый, голубой, зелёный) и тонкой рамкой. В настройках это можно выключить.
- Тап по блоку открывает внизу экрана оригинал и полный перевод. Оранжевый уголок у блока означает, что текст в нём обрезан.
- Настройка размера текста теперь задаёт максимальный размер (от 6 sp), меньший подбирается автоматически.

Из v0.10: одно распознавание без дублей, выделение области с удержанием 1 секунду до любого края экрана, исправлены координаты.

Не проверено на устройстве. Установка: заменить файлы в GitHub Desktop, Commit, Push, скачать APK из GitHub Actions.
