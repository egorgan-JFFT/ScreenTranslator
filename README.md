# Screen Translator v0.12

Новое: перевод вводимого текста.
- Когда вы печатаете в другом приложении (курсор в поле ввода, клавиатура открыта), под кнопкой TR появляется кнопка «RU→ZH».
- Нажатие переводит текст из поля на язык оригинала и вставляет перевод в то же поле.
- Язык: с языка перевода на язык оригинала. Если выбран язык «Авто», используется язык последнего перевода экрана (по умолчанию китайский).
- Если поле не принимает текст или оно пустое, открывается окно: в нём можно написать или поправить текст, перевод копируется в буфер обмена.
- Работает через службу специальных возможностей «Экранный переводчик: перевод ввода». В настройках приложения есть кнопка «3. Включить перевод ввода» и статус, включена ли служба.
- Пароли не читаются.

Из v0.11: перевод на месте оригинала, блоки разделены цветом, тап по блоку показывает полный текст.

Не проверено на устройстве. Установка: заменить файлы в GitHub Desktop, Commit, Push, скачать APK из GitHub Actions.
