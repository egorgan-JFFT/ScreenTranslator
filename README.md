# Screen Translator v0.8

Основано на рабочей версии v0.7: **свайп вверх по слою перевода сохранён**, двойной тап и кнопка ✕ не возвращались.

- Кнопка TR квадратная: 52dp × 52dp.
- После остановки при перетаскивании на 2 секунды указатель появляется в **левом верхнем углу TR**.
- Рамка растягивается от этого угла до левого верхнего угла текущего положения TR; отпускание запускает перевод области.
- Одно нажатие TR переводит весь экран.
- Возвращены выбор источника и цели перевода, обмен языков, Google Cloud Translation API key, Baidu App ID и Secret, выбор переводчика.
- Google Cloud Translation v2 и Baidu VIP Translate вызываются через HTTPS; для них требуются действительные учётные данные, возможна тарификация.
- Офлайн ML Kit остаётся по умолчанию, выбор языков теперь используется и при переводе.
- API-ключи сохраняются в обычных SharedPreferences; **не рекомендуется использовать постоянные неограниченные ключи**. Ограничьте ключи по API/квотам и при необходимости используйте свой прокси-сервер.
- При автоматическом определении языка OCR может ошибаться, особенно на коротких строках.

Сборка GitHub Actions и тестирование на телефоне **ещё не выполнялись**.

## Установка
Распакуйте ZIP в локальную папку репозитория с заменой файлов. GitHub Desktop: Commit → Push origin. Скачайте APK в GitHub Actions.
