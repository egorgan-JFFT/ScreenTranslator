# Screen Translator v0.6.2 — исправление закрытия перевода

Добавлена отдельная кнопка **✕** в правом верхнем углу экрана, которая отображается **поверх** перевода. Нажатие удаляет и перевод, и кнопку ✕.

Причина изменения: перевод рисуется в полноэкранном окне с `FLAG_NOT_TOUCHABLE`; свайп по нему не может быть обработан. Новая кнопка — отдельное активное окно, добавляемое после слоя перевода, чтобы оно оставалось доступным.

Также сохранено закрытие через кнопку TR, если она доступна, и свайп вверх по TR. Удаление слоёв теперь защищено от повторных вызовов.

Обновление: распаковать в локальный репозиторий, заменить файлы, GitHub Desktop → Commit → Push, скачать APK из Actions.

**Сборка и тестирование на телефоне не проводились.**
