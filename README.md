# Screen Translator v0.9

Исправления:
- Переведённые фрагменты располагаются с учётом уже нарисованных блоков, поэтому текст больше не должен накладываться друг на друга.
- Перенос длинных строк и слов; ширина блока больше не ограничена шириной китайского оригинала.
- При перетаскивании TR виртуальная позиция кнопки может уходить за край экрана; рамка выделения следует за ней и ограничивается границами экрана.
- При отпускании TR возвращается в видимую область.
- Свайп вверх для закрытия, онлайн-переводчики, ключи API и выбор/обмен языков сохранены.

Ограничение: если переведённого текста физически больше, чем помещается на экран, часть блоков пропускается, чтобы они не перекрывались. В будущем можно добавить прокручиваемую панель.

Не проверено компиляцией и на устройстве. Установка: заменить файлы в GitHub Desktop, Commit, Push, скачать APK из GitHub Actions.
