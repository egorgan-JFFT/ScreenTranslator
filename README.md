# Screen Translator v0.10

Изменения:
- Блоки перевода больше не пропускаются. Если текст не помещается, шрифт уменьшается (до 60%), а если и так не влезает, перевод можно прокрутить пальцем.
- Распознавание выполняется одним движком по выбранному языку, без повторных проходов и дублей. «Авто» и «Китайский» используют китайский движок, который читает и латиницу.
- При выделении области распознаётся только она.
- Новое выделение: подержите TR 1 секунду (было 2). Рамка охватывает кнопку в начальной и текущей позиции, поэтому достаёт до любого края экрана, а кнопка не уходит за край. Красные уголки показывают точные границы.
- Координаты окон считаются от края экрана с учётом строки состояния, поэтому перевод и рамка не смещаются.
- Кнопка TR остаётся поверх перевода, её нажатие закрывает перевод. Справа вверху есть крестик.

Не проверено на устройстве. Установка: заменить файлы в GitHub Desktop, Commit, Push, скачать APK из GitHub Actions.
