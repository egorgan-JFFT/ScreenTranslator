# Screen Translator v0.6

Android 10 / MIUI 12, Chinese and other OCR scripts, screen overlay.

## Controls
- Tap floating TR once: translate whole screen (340 ms wait to distinguish double tap).
- Double tap TR within 330 ms: toggle region-selection mode; next single tap allows dragging a rectangle.
- Tap TR again to clear prior overlaid translation and translate again.
- The default display is translated text placed over the recognized original.

## Translation providers
- Offline ML Kit (default): downloads language models on first use; needs internet for downloads.
- Google Cloud Translation API v2: requires **your own Google Cloud API key** with Cloud Translation API enabled and billing configured.
- Baidu Translate API: requires **your own Baidu App ID and secret** for its translation API.
- Keys are saved in Android SharedPreferences on the device (not encrypted). Do not use high-privilege or unrestricted API keys. Online text is transmitted to the selected provider.
- Provider, source language (including Auto), target language, and swap are in the app settings. Supported UI languages: Chinese, English, Japanese, Korean, Russian.
- Region selection and language identification are best-effort; OCR may mistake characters or detect the wrong language, especially for short text.

## Build
GitHub Actions -> Build Android APK -> Artifacts -> ScreenTranslator-APK.
Project source is not locally compiled/tested in this environment. APK is generated by GitHub Actions.

## Known limitations
- Online providers may incur charges and require separately registered credentials.
- Overlays use solid backgrounds and do not reconstruct the image beneath the original text.
- Screen capture may be restricted in protected apps.
- Automatic language detection is not perfect, particularly for short strings.
- Android 10 is the primary target; compatibility on other Android versions not verified.
