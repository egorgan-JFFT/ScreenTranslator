# Screen Translator v0.7

Восстановлена схема управления без двойного нажатия и без кнопки ✕.

- Одно нажатие TR: перевод всего экрана.
- Свайп вверх по слою перевода: убрать перевод.
- Перемещение TR: переместить кнопку.
- Если при перетаскивании остановить палец на 2 секунды, появляется маленькая жёлтая стрелка в точке фиксации.
- Продолжайте тянуть кнопку: от стрелки растягивается жёлтая рамка области.
- Отпустите палец: переведётся только выделенная область.
- Если область слишком мала, перевод не запускается.
- Настройки OCR и оформления взяты из v0.5.

Изменения основаны на v0.5, без кода двойного нажатия из v0.6. Указатель/рамка реализованы отдельным неинтерактивным overlay; кнопку можно продолжать перетаскивать.

Внимание: сборка и поведение на телефоне не проверены. После GitHub Actions проверить жест закрытия и выделение области.
